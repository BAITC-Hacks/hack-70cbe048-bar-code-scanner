# Barcode Price Scanner — исследование

Рынок: Казахстан, стартовый город: Астана. Приоритет: сравнение цен сетей.

Статус: исследование выполняется. Вывод о жизнеспособности ещё не сделан.

Материалы: `docs/research-summary.md`, `docs/mvp-recommendation.md`, `docs/risks.md`.
Полевой протокол: `docs/field-protocol.md`; правовые ограничения: `research/legal/README.md`.
Ход работы: `research-log.md`; статусы направлений: `research/status.md`.
Экспериментальные скрипты изолированы в `experiments/`; это не production-приложение.

Правило: наблюдаемая цена не равна гарантированной цене на кассе. Различать канал, филиал,
условия лояльности, время получения и время обновления источником. Предел наблюдений — 7 дней.
