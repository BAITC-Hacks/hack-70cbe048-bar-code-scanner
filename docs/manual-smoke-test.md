# Ручной smoke-test

1. Запустите `npm run dev`.
2. Откройте UI и выберите Астана.
3. Введите `4870207314301`; ожидается `found`, Galmart, цена из текущего публичного каталога, ID 163043, время и предупреждения.
4. Введите `4870207314530`; ожидается отдельный `not_found`.
5. Введите `0000000000000`; ожидается HTTP 400, а не найденный товар.
6. Переключите Алматы и повторите: API должен передать City 1.
7. Для реального источника выполните `npm run smoke -- 4870207314301 astana`; это единственный ручной live-запрос и может измениться при недоступности Galmart.
