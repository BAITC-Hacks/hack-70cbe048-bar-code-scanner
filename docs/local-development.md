# Локальный запуск

Нужен Node.js 20+. Скопируйте `.env.example` в `.env`, затем выполните `npm install` и `npm run dev`. Откройте `http://localhost:5173`. Для телефона в одной Wi-Fi сети используйте IP компьютера и порт Vite, разрешив входящие подключения в локальной сети. Для камеры нужен HTTPS или localhost; ручной ввод работает без камеры.
