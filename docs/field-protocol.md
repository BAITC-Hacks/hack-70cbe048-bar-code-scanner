# Полевая проверка в Астане

Цель — проверить разницу между ответом источника, ценником и кассой. Выполнить на 5–10 товарах, не выдавая результат как репрезентативный опрос.

Для каждой покупки записать:

| Поле | Что фиксировать |
|---|---|
| Магазин | сеть, точный адрес, филиал/store ID если виден |
| Время | локальная дата и время сканирования, фото и покупки |
| Товар | EAN, бренд, полное название, фасовка/единица |
| Полка | цена, валюта, old/new price, акция, club/member condition |
| API | источник, city/store parameter, retailer product ID, retrieved_at |
| Касса | цена в чеке и чек с удалёнными телефоном, картой, ФИО и адресом |
| Результат | exact match / mismatch / unavailable / unknown |

Сфотографировать штрихкод и ценник так, чтобы они относились к одной упаковке. Не фотографировать лица и чужие чеки. Передавать чек в исследование только после удаления персональных данных. Весовые товары, внутренние магазинные коды, наборы и loyalty-only цены помечать отдельными категориями и не смешивать с обычными EAN.

Критерий пилота: для каждого из пяти товаров источник и физический товар однозначно совпадают; расхождения сохраняются, а не исправляются вручную. Совпадение в одном магазине не доказывает точность всех филиалов.
