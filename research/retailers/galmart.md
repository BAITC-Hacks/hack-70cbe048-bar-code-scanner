# Galmart: подтверждённый EAN → товар → онлайн-цена

Дата проверки: 20.09.2026 (локальные часы Windows +05:00; UTC записан в JSON). Статус направления: **Validated** для технической цепочки, **Evidence found** для филиальности. Итог сети: **Confirmed для онлайн-каталога города, Partially confirmed для исходного сценария цены конкретного магазина**.

## Что воспроизведено

Официальный сайт отдаёт публичный JavaScript-клиент. В нём обнаружены GET `/api/v2/catalog/goods/?search=...`, `/api/v2/catalog/goods/{id}/`, `/api/v2/addits/shops/` и заголовок `City`. Запросы выполнены без аккаунта и токенов; никаких действий с заказами или обхода защиты.

`City: 2` соответствует Астане, `City: 1` — Алматы согласно [справочнику магазинов](https://galmart.kz/api/v2/addits/shops/). Для товара API выдаёт id, articul, title, price, old_price, unit, unit_value, unit_price, inventory, available, currency. Поле `articul` — отдельный внутренний артикул, его нельзя считать EAN. Поиск по проверенному EAN действительно возвращает конкретный товар, хотя EAN не дублируется в ответе.

## Ограничения смысла цены

- **FACT / HIGH:** цены отличаются между городами: Coca-Cola 1000 мл, ID 10528, Астана 785 ₸, Алматы 700 ₸; остальные четыре проверенных Coca-Cola совпали. Нельзя кешировать цену только по product ID.
- **FACT / HIGH:** ответ каталога не содержит идентификатора обслуживающего филиала или времени обновления цены. Восьми адресов Астаны в справочнике недостаточно, чтобы приписать каждому цену каталога.
- **FACT / HIGH:** для весовых блинчиков ID 9553 `price=2680`, `unit=кг`, `unit_value=0.3`, `unit_price=804`. Цена выбранной порции и за килограмм — разные поля. Внутренний код из PDF 2857067 не найден поиском, переносить внутренние коды между сетями нельзя.
- **FACT / HIGH:** у Asu и Pepsi есть old_price; доступная каждому цена API не означает персональную скидку. Условия и срок акции в ответе не установлены; cashback в выборке null. Личный кабинет не исследовался.
- **UNKNOWN / UNKNOWN:** соответствие цены на полке/кассе, доступность конкретного филиала, период обновления источника, поведение товара `available=false`. Все успешные EAN в выборке были доступны; пустой поиск не равен отсутствию товара на складе.
- **INFERENCE / HIGH:** пригоден исследовательский прототип онлайн-цен по городу. Обещание «точная цена у этой кассы» пока не подтверждено.

## Правила использования и воспроизведение

[robots.txt](https://galmart.kz/robots.txt) разрешает общий обход и запрещает `/catalog/search`, `/account/`, `/orders/`, `/basket/`. Проверялся конкретный API-путь, найденный в клиенте; разрешение robots не является лицензией. [Публичная оферта](https://galmart.kz/legal/oferta), также полученная через `/api/v2/addits/legal/`, предупреждает о справочном характере материалов и возможности изменения цены (3.5, 5.3–5.4). Разрешение на коммерческое агрегирование/повторную публикацию базы не установлено. Для запуска нужен согласованный доступ или отдельная правовая оценка; договор покупателя не трактуется как API-лицензия.

Скрипт: `experiments/retailer-price-fetch/galmart-probe.ps1`. Параметр `-Ean` принимает список кодов; `-OutputPath` меняет файл результатов. Компактные факты HTTP, заголовки, даты, товар и цена сохранены в `galmart-results.json`, справочник и robots — в `galmart-source-metadata.json`. Описания, фото и полный JavaScript не сохранялись. `source_updated_at=null` означает, что свежесть первичной цены неизвестна даже при свежем `retrieved_at`.
