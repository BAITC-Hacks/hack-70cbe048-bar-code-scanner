# Magnum: публичный каталог и отдельный barcode-checker

Проверено 20.09.2026. Статус: **Partially confirmed** для онлайн-промокаталога; **Unknown** для публичного EAN-поиска через найденный web API.

Официальное приложение Magnum Club в Google Play прямо заявляет возможность узнавать цену по штрихкоду, а сайт Magnum отдаёт публичный Strapi API на `https://magnum.kz:1337/api`. Без авторизации воспроизведены `GET /cities`, `/shops`, `/products` и `/new-product`. `cities` возвращает Астану с id 3 и loyalty id 2; `/shops` возвращает адреса и координаты филиалов. `/products` возвращает retailer id, название, `start_price`, `final_price`, даты акции, изображения и привязанные магазины.

API дал реальные промотовары и цены: например, «Завтрак Nestlé Хрутка Duo 650 г» 1 599 ₸ (акция 17–23.09.2026) и масло «Все в дом» 5 л 4 229 ₸. Имена файлов изображений содержат похожие на EAN числа, но это не подтверждает, что поле изображения является barcode. Поиск по этим кандидатам, по EAN Coca-Cola и по названию EAN не подтвердил `EAN → retailer product` в API. Поэтому нельзя объявлять Magnum EAN-цепочку найденной.

**FACT / HIGH:** публичный API существует, цены и даты акций доступны; филиалы представлены отдельно. **FACT / HIGH:** приложение заявляет barcode price check. **UNKNOWN:** endpoint приложения, условия club/member price, точная связь товара с EAN и кассовое соответствие. Источник не сообщает `source_updated_at`; дата акции — не обязательно дата обновления цены.

`robots.txt` сайта вернул 404 в проверке. Публичность API не является лицензией на коммерческое копирование каталога; для production нужен договор или правовая оценка. Исходные HTTP-манифесты находятся в `.cache` (gitignored), общий probe — `experiments/retailer-price-fetch/probe.mjs`.
