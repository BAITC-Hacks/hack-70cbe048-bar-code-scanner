# Legal / ToS границы

Проверка выполнена 20.09.2026. Это техническая оценка источников, не юридическое заключение.

| Источник | Технический факт | Ограничение | Production-safe |
|---|---|---|---|
| Galmart API | Публичные GET без аккаунта; robots допускает общий обход и запрещает отдельные пути | Оферта предупреждает о справочном характере и изменении цен; лицензия агрегирования не найдена | Только после согласия/договора или отдельного review |
| Magnum API | Публичные GET catalog/cities/shops | Публичность endpoint не даёт права на повторную публикацию каталога | Не подтверждено |
| Toimart | Сайт и промоблоки доступны, robots разрешает `/` | EAN mapping не найден; ToS/лицензия агрегатора не подтверждены | Не подтверждено |
| Small Food / Wolt | Wolt-страница технически содержит GTIN, филиал и цену | Wolt Kazakhstan Terms 13.6 запрещают сбор/копирование без согласия и bots; 12.1 закрепляет права на каталог | Нет без разрешения; использовать только как проверку гипотезы |
| Open Food Facts / OBF | Внешняя база пригодна для enrichment | Лицензии и attribution должны быть соблюдены; цена там не хранится | Отдельная оценка лицензии и совместимости |
| Пользовательские фото/чеки | Пользователь может дать наблюдение | Согласие, персональные данные чеков и права на изображения | Нужны правила, redaction и consent |

`robots.txt` — инструкция обхода, а не договор и не разрешение на коммерческое использование. Техническая возможность и production-safe/legal возможность в отчётах разделены.
