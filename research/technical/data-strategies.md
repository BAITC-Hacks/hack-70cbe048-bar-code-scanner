# Стратегии источников данных

Оценка для Астаны по состоянию на 20.09.2026: `HIGH` означает подтверждено экспериментом, `UNKNOWN` — не проверено.

| Метод | Точность | Свежесть | Сложность | Масштаб | Правовой риск | Demo |
|---|---|---|---|---|---|---|
| Официальный API | Высокая при договорённости | Высокая | Средняя | Высокий | Низкий после договора | Да |
| Публичный undocumented API | Неизвестна филиальность | Высокая | Средняя | Средний | Средний/высокий | Да, Galmart |
| Scraping | Зависит от сайта | Средняя | Средняя | Низкий/средний | Средний/высокий | Да, только с разрешением |
| Партнёрская выгрузка | Высокая | По SLA | Средняя | Высокий | Низкий | Да |
| Crowdsourcing | Наблюдаемая | Средняя | Средняя | Средний | Низкий при consent | Да |
| Чеки + OCR | Высокая для покупки | Историческая | Средняя/высокая | Средний | Средний (PII) | Да |
| Фото ценника | Локальная полочная | Время фото | Средняя | Средний | Низкий/PII | Да |
| Ручной merchant feed | По SLA | По загрузке | Низкая/средняя | Высокий | Низкий | Да |
| Гибрид | Зависит от fallback | Высокая | Высокая | Высокий | Средний | Да |
